Continuity Prompt Builder

Lock your cast once, break the scene into ≤8-second beats, and generate paste-ready image + video prompts that carry identity and continuity forward — so characters stay consistent and clips stop morphing.

1 Cast & anchors

Define each recurring subject once. The descriptor is pasted verbatim into every shot (reworded attributes are the #1 cause of morphing). Then add each subject as an Ingredient in Flow — a clean reference image on a plain/segmented background, no extra people, matched lighting — this is what locks identity across clips.

2 Global look

Style, environment and guardrails shared by every shot. Environment and uniforms follow the Porsche WBT image rules.

3 Shot beats

One subject, one action, static camera per beat. Keep each ≤8s. Beats after the first automatically seed the previous clip's last frame.

Anti-morph checklist

→One action per clip. Simultaneous actions break geometry.
→Static camera. Any push-in/pan/zoom makes the model warp the background.
→Keep subjects in-frame. Exits/returns morph on re-entry.
→Seed the last frame. Clip N's end frame = clip N+1's start frame — or use Extend for one continuous shot.
→Verify before chaining. Errors compound down the sequence.
→Add Ingredients. Clean character refs on a plain background lock identity across clips — the key fix.
→Prompt = motion only. Don't re-describe appearance the frames/ingredients already fix.

Generated prompts

In Flow: add each character as an Ingredient, then per beat use Frames to Video (start + end frame) with the ingredients attached; reuse each clip's end frame as the next clip's start frame, or use Extend for one continuous shot. Keep the camera static. Saved locally in your browser.
